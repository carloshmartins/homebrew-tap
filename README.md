# carloshmartins/tap

Homebrew formulae by [carloshmartins](https://github.com/carloshmartins).

## proof

Evidence that an iOS change actually works, for coding agents and the people reviewing their work.
Docs: https://carloshmartins.github.io/proof

```sh
brew install carloshmartins/tap/proof
proof setup
```

The formula builds proof from source with your Xcode (macOS 14+, Xcode 16+).
